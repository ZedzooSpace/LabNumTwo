## Описание задач, алгоритмов и реализации

### Задача 1. Точка координат
* **Текст задачи:** Создайте сущность Точка, расположенную на двумерной плоскости, которая описывается координатами $X$ и $Y$. Может возвращать текстовое представление вида {X;Y}. Необходимо создать три точки с разными координатами и вывести их на экран.
* **Алгоритм и реализация:**
    * Реализован класс Point с закрытыми (private) полями x и y типа double.
    * В методе toString() добавлен условный вывод: если координата является целым числом, она отображается без дробной части.

---

### Задача 2. Имена
* **Текст задачи:** Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Предусмотреть возможность того, что какой-либо из параметров может быть не задан (тогда он не учитывается при приведении к строке). Создать варианты имен: *Клеопатра*, *Пушкин Александр Сергеевич*, *Маяковский Владимир*.
* **Алгоритм и реализация:**
    * Реализован класс Name с конструкторами для разных наборов параметров.
    * В методе toString() используется StringBuilder: склеиваются только те компоненты имени, которые не равны null и не являются пустыми строками.

---

### Задача 3. Прямая
* **Текст задачи:** Создайте сущность Линия, которая описывается точкой начала и точкой конца. Продемонстрировать связывание линий через общие точки, изменение координат точек и замену объекта точки начала без изменения третьей линии.
* **Алгоритм и реализация:**
    * Класс Line хранит ссылки на объекты Point (start и end).
    * Демонстрируется агрегация: если Линия 3 создается из ссылок line1.getStart() и line2.getEnd(), то при мутации начальной точки Line 1 изменяется и Line 3. Замена ссылки через setStart(new Point(...)) разрывает эту связь для Line 3.

---

### Задача 4. Города (Схема)
* **Текст задачи:** Создайте сущность Город, представляющую точку на карте с названием и набором путей к другим городам (где путь — это сочетание города-назначения и стоимости). Реализовать представленную в методичке схему графа.
* **Алгоритм и реализация:**
    * Реализован вспомогательный класс Path (хранит ссылку на целевой City и стоимость cost).
    * Класс City содержит список связанных путей List<Path>.
    * Добавление путей выполняется методом addPath(City dest, int cost).

---

### Задача 5. Создаем Города (Конструкторы)
* **Текст задачи:** Измените сущность Город. Должна быть возможность создать город, указав только название, либо название и готовый список путей к другим городам.
* **Алгоритм и реализация:**
    * В классе City перегружены конструкторы:
        1. City(String name) — инициализирует пустой список путей ArrayList.
        2. City(String name, List<Path> paths) — защитно копирует переданный список путей в новое коллекционное хранилище.

---

### Задача 6. Дроби
* **Текст задачи:** Создайте сущность Дробь со свойствами числитель и знаменатель. Реализовать методы для операций сложения, вычитания, умножения и деления с другой дробью или целым числом. Результатом операции должна быть новая Дробь.
* **Алгоритм и реализация:**
    * Реализован класс Fraction.
    * В конструкторе проверяется деление на ноль, а также приводится знак.
    * Сокращение дробей выполняется через приватный метод поиска НОД.
    * Методы sum, minus, multiply, div возвращают новые экземпляры Fraction. Методы перегружены для приема int.
